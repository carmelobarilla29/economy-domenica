# Domenica Economy

Web app personale per Domenica, con tema rosa e icona per la home dell'iPhone.

Apri l'app: https://carmelobarilla29.github.io/economy-domenica/

Su iPhone, apri il link in Safari e scegli **Condividi → Aggiungi alla schermata Home**.

Parte vuota: contanti, conto e risparmi si possono impostare toccando le relative
schede. I dati sono salvati solo nel browser del dispositivo. Da Impostazioni
si può copiare un backup e ripristinarlo. Conservare periodicamente una copia.

Questa repository e l'archivio `domenicaeconomy.v1` sono separati dalle altre app
Economy. Non vengono importati dati da altre versioni e gli aggiornamenti non
azzerano l'archivio. Il codice è pubblico; i dati inseriti non sono caricati su GitHub.

L'app è contenuta in `index.html`, senza build o dipendenze. `icon.svg` e
`apple-touch-icon.png` sono le icone. GitHub Pages pubblica da `main`, cartella radice.
